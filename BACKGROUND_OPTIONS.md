## 📷 Supported Image Formats

### ✅ Best Formats:

| Format | Quality | Size | Transparency | Animation | Best For |
|--------|---------|------|--------------|-----------|----------|
| **JPEG/JPG** | High | Small | ❌ No | ❌ No | Photos, gradients |
| **PNG** | Best | Large | ✅ Yes | ❌ No | Sharp graphics, text |
| **WEBP** | Best | Smallest | ✅ Yes | ✅ Yes | Modern browsers |
| **SVG** | Vector | Tiny | ✅ Yes | ✅ Yes | Patterns, icons |
| **GIF** | Low | Medium | ✅ Yes | ✅ Yes | Simple animations |

### 🎯 Recommended:
1. **JPEG** - Best for photos (like your current background)
2. **PNG** - Best for sharp graphics with transparency
3. **WEBP** - Best overall (small size + high quality)

## 🔧 How to Change Background

### Method 1: Replace File (Easiest)
1. Download your chosen wallpaper
2. **Convert to JPEG** (if needed):
   - Use: https://cloudconvert.com/png-to-jpg
   - Or use Paint → Save As → JPEG
3. Rename to `frontendBG.jpeg`
4. Replace: `d:\JUNIOR\front-end\src\components\frontendBG.jpeg`
5. Refresh browser (Ctrl+Shift+R)

### Method 2: Add New File
1. Save image in `d:\JUNIOR\front-end\src\components\`
2. Open `d:\JUNIOR\front-end\src\App.css`
3. Find `.app-container`
4. Change:
```css
.app-container {
  background-image: url('./components/YOUR_IMAGE.jpg');
}
```
5. Save and refresh browser

### Method 3: Use URL
```css
.app-container {
  background-image: url('https://example.com/wallpaper.jpg');
}
```
